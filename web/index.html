Convergence criteria

Each row is a precision the engine asks of a run: enough hits on every outcome, a small enough relative standard error on every mean, enough periods in the tail. "Planned periods" is how many the plan expected the criterion to need, "observed" the value this run reached, and "met" says whether the criterion's target was reached. A run here is the fixed number of periods above, so a "no" means the run was too short for that criterion; the engine's own adaptive runs continue until every row is met.
